# Hangar

A small IaaS cloud built directly on Cloud Hypervisor: VMs and containers both
run as microVMs, managed through a declarative, Kubernetes-style API.

Early development; nothing runs yet.

- Start with `AGENTS.md`: layout, commands, and the docs index.
- `docs/architecture.md` describes the target system.
- `docs/decisions/` explains why it is shaped this way.
